QUICK START FOR NEW PC
================================================================================

Step 1: Prerequisites
--------------------
Install required software:
- Node.js 18.x or 20.x
- OpenJDK 11 (NOT 17 or higher!)
- Android SDK command line tools
- Git

Ubuntu Installation:
```bash
# Node.js (using nvm)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 20

# JDK 11
sudo apt install openjdk-11-jdk -y

# Git
sudo apt install git -y
```

Step 2: Clone Repository
-----------------------
```bash
git clone <repository-url>
cd ceramic_mobile_app/mobile_automation_test
```

Step 3: Run Automated Setup
--------------------------
```bash
chmod +x setup.sh
./setup.sh
```

This will:
- Check prerequisites
- Install Node.js dependencies
- Configure Android SDK
- Create Android emulator
- Build the application
- Setup test database

Estimated time: 10-20 minutes (longer on first run)

Step 4: Start Backend Server
---------------------------
In a separate terminal:
```bash
cd ceramic_mobile_app/back_end
gunicorn app.main:app --workers 4 --bind 0.0.0.0:8002
```

Step 5: Run Tests
----------------
```bash
./run-tests.sh
```

================================================================================
USAGE EXAMPLES
================================================================================

Basic Usage
-----------
# Run all tests
./run-tests.sh

# Run with help
./run-tests.sh --help

Specific Tests
--------------
# Login tests only
./run-tests.sh --file e2e/auth/login.test.js

# Registration tests only  
./run-tests.sh --file e2e/auth/register.test.js

# Specific test by name
./run-tests.sh --pattern "should login successfully"

Debug Mode
----------
# Run with console logs (slower but more info)
./run-tests.sh --debug

# Debug specific test
./run-tests.sh --debug --file e2e/auth/login.test.js

Advanced Options
---------------
# Start backend automatically
./run-tests.sh --backend

# Clean old artifacts
./run-tests.sh --cleanup

# Combine multiple options
./run-tests.sh --debug --backend --cleanup --file e2e/auth/login.test.js

================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "JAVA_HOME is set to an invalid directory"
Solution:
  export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
  
Issue: "Emulator not found"
Solution:
  ./setup.sh  # Re-run setup to create emulator
  
Issue: "Connection refused"
Solution:
  # Start backend server
  cd ../back_end
  gunicorn app.main:app --workers 4 --bind 0.0.0.0:8002

Issue: Tests timing out
Solution:
  ./run-tests.sh  # Use release build (default, faster)

Issue: "npm install" fails
Solution:
  rm -rf node_modules package-lock.json
  npm install
