WEDNESDAY May 20 — F-005 Day 2 (Continuation + Bar Patterns)
--------------------------------------------------------------------------------
  Service : ai-insights-service
  Ticket  : F-005 (part 2 of 3)

  Patterns to implement today:
    - Flag + Pennant
    - Symmetrical / Ascending / Descending Triangle
    - Gap (common, breakaway, runaway, exhaustion)
    - Wide-Ranging Day (WRD)

  Steps:
    1. Flag / Pennant:
         - Strong directional move (pole) followed by tight consolidation.
         - Flag: parallel channel consolidation.
         - Pennant: converging trendlines consolidation.
    2. Triangles:
         - Symmetrical: converging highs + lows.
         - Ascending: flat top + rising lows.
         - Descending: falling highs + flat bottom.
    3. Gaps:
         - Breakaway: gap at start of trend, heavy volume.
         - Runaway (measuring): gap mid-trend.
         - Exhaustion: gap near end of trend, filled quickly.
         - Common: fills within a few bars, no trend context.
    4. Wide-Ranging Day (WRD):
         - Bar range > N * ATR(14); note open/close position within range.
    5. Add unit tests for each new detector.

    Ticket  : F-006
    Depends : F-003 (typed S/R levels) + F-005 (pattern catalog)

    Definition:
      Bull trap: price penetrates resistance -> closes back BELOW resistance
                 within N bars.
      Bear trap: price penetrates support -> closes back ABOVE support
                 within N bars.

    Steps:
      1. Load typed S/R levels from F-003.
      2. Scan recent bars for penetration events.
      3. Check if price reverts inside range within N bars (configurable, default 3).
      4. Return: { type: "bull_trap"|"bear_trap", severity: float,
                   bar_index: int, level_breached: float }
