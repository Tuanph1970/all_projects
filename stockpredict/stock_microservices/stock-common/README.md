# Stock Common Library

Shared utilities and common functionality for the Stock Helper microservices.

## Contents

- **config**: Configuration management with environment variables
- **middleware**: Request logging, correlation ID, security middleware
- **events**: Event bus for async messaging with RabbitMQ
- **tracing**: Distributed tracing with OpenTelemetry
- **cache**: Redis caching utilities
- **database**: Database connection and session management

## Installation

```bash
pip install -e /path/to/stock-common
```
