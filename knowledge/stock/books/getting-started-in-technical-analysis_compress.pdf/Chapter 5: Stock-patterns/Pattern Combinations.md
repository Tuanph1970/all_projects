# Pattern Combinations for Enhanced Significance

## The Principle

Single patterns carry moderate conviction. Multiple independent patterns at the same location compound signal strength non-linearly.

## Why Combinations Work: Independence of Evidence Types

Each pattern represents a *different type* of evidence:

- **Spikes** = climactic exhaustion (momentum evidence)
- **Reversal days** = close-based rejection (sentiment evidence)
- **Wide-ranging days** = volatility shift (regime-change evidence)
- **Flags** = consolidation after initial move (trend-establishment evidence)
- **Gaps** = price discontinuity (urgency evidence)
- **S/R levels** = historical price memory (structural evidence)

When multiple independent types converge, the probability of a genuine signal rises non-linearly. Like multi-factor authentication in security — one factor is breakable, three together are very hard to break.

## The Deutsche Mark Masterclass (Fig 5.32)

Three independent evidence types aligned before official confirmation:
1. Two peaks at same level (structural)
2. Spike high at peak 2 (momentum exhaustion)
3. Flag after initial decline (trend establishing)

## Rule #76: The Meta-Combination

> A failed signal is more reliable than the original signal.

A pattern that was itself a combination, which then fails → produces an even stronger counter-signal. Failed combinations are Schwager's highest-conviction setups.

## Combinations as Risk Reducers

Multiple patterns tightening stop zones: spike extreme + flag boundary + S/R level → much more reliable stop than any single level alone.
